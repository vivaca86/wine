# Footwear Worn Image Study (Ecommerce)

Microscopic visual study notes for AI-generated **footwear worn/on-foot** images (product-page style), written to support later prompting and QA.

## Runs

- `2026-04-26-run-01.md` — Materials + barefoot/hosiery/socks layering study (starter library).

## How to use

- Treat each run as a “visual checklist” and a prompt-phrase library.
- Prefer *close-up crop targets* (toe box, vamp, heel counter, outsole edge, ankle opening, hosiery toe area) and validate against the QA checklists.
