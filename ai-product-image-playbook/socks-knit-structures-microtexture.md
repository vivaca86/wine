# Socks (No-show → Crew → Terry Sports): Knit Structure + Pressure Cues

Last updated: 2026-04-27

This file is for **sock realism at zoom**: knit gauge, yarn fibers, ribbing, heel pocket shaping, toe seams, and elastic pressure marks.

Primary goal: socks should read like real textiles with structure, not painted-on fabric noise.

---

## Layer Model

1. **Foot layer**: toe shapes, heel curve, ankle bones, subtle skin compression.
2. **Sock layer**: yarn + knit structure, toe seam, heel pocket, arch band, cuff.
3. **Shoe-contact layer**: collar pressure, folds that match thickness, realistic bunching.

---

## Sock Types and Micro Cues

### No-show socks

- Thin knit; clean edge near shoe opening.
- Tension around arch/heel; minimal bulk.

Prompt fragments:

- “thin no-show socks with clean edge; subtle knit texture; arch tension band; no bulky folds”

### Dress socks (thin)

- Fine gauge knit; minimal fuzz; subtle ribbing.
- Toe seam should be minimal (often linked), not a thick ridge.

Prompt fragments:

- “fine-gauge dress socks with subtle rib knit; minimal toe seam ridge (linked seam)”

### Crew socks / casual cotton

- More visible yarn; ribbed shaft; cuff pressure mark possible.
- Heel pocket shaping should be visible as a change in knit direction.

Prompt fragments:

- “ribbed crew socks with visible knit columns; shaped heel pocket; subtle cuff indentation on skin”

### Terry sports socks

- Cushioning from **terry loops**: interior loop pile that can peek at edges; thicker feel.
- Often has arch support band; thicker toe/heel zones.

Prompt fragments:

- “terry-cushioned sports socks with visible terry loop texture; thicker heel/toe zones; arch support band”

Reference anchor:

- Terry loops as cushioning structure.
  - https://darntough.com/blogs/the-alternate-stitch/what-is-terry-loop

### Wool socks (merino blends)

- Slightly fuzzier surface; soft halo; thicker knit; less crisp rib lines.
- Avoid making it look like shaggy hair.

Prompt fragments:

- “merino wool sock knit with soft fiber halo; thicker knit; realistic fuzz (not hairy)”

## Toe Seam (Huge Tell)

### What to request

- Toe seam should exist but be subtle (especially on quality socks).
- “Linked toe seam” / “hand-linked” implies a flatter seam profile.

Prompt fragments:

- “flat linked toe seam (minimal ridge); no thick bulky toe seam”

Reference anchors:

- Sock toe seam types and construction terminology.
  - https://ecosox.com/blogs/news/best-toe-seams-for-socks

---

## Heel Pocket Construction

### Visual cues

- Heel pocket is a shaped knit zone: look for knit-direction change and a curved seam impression.
- Heel should sit centered; avoid twisted socks.

Prompt fragments:

- “shaped heel pocket aligned correctly; knit direction changes around heel curve”

---

## Ribbing, Cuff, and Pressure Marks

### What to request

- Ribbing: vertical knit columns; spacing consistent; compresses around ankle.
- Cuff pressure: faint indentation line and slight skin bulge above cuff (subtle).

Prompt fragments:

- “ribbed cuff compresses slightly; faint sock mark indentation; realistic pressure”

Reference anchor:

- Sock marks are commonly from pressure/elastic; use as realism justification.
  - https://www.healthline.com/health/sock-marks-on-legs

---

## Shoe-Collar Interaction

### What to request

- Thin socks: subtle outline of toe/heel can show through only in very tight areas.
- Thick socks: bulk creates real folds/bunching near collar; folds should match thickness.

Prompt fragments:

- “sock folds match thickness; no paper-thin wrinkles on thick socks”
- “subtle collar pressure into sock; no collar cutting through fabric”

---

## Negative Constraints

- “no printed sock texture; knit must be structural (yarn + ribbing), not noise”
- “no twisted heel pocket; no misaligned toe seam running diagonally”
- “no sock material turning into smooth leggings”

---

## QA Checklist (Socks)

Reject/regenerate at zoom if:

- Ribbing turns into random stripes.
- Toe seam becomes a thick rope or disappears entirely.
- Heel pocket is missing (tube sock look) when you requested shaped socks.
- Terry texture looks like random bumps rather than loop pile.
- Cuff pressure is either absent (mannequin) or extreme (tourniquet).
